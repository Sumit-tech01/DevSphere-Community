## 5. Deliverables

Participants submit:

- A live demo link, if available.
- One or two screenshots.
- A README explaining setup and decisions.
- A short reflection: what was learned, what was difficult, and what would change.
- A completed self-check against the rubric.

## 6. Submission instructions

1. Read the full challenge.
2. Build the solution in your own repository.
3. Test the requirements and accessibility.
4. Post in **Project Showcase** with the title:

   ```text
   [Challenge NNN] Your Name — [Challenge title]
   ```

5. Include the required links and reflection.
6. Give constructive feedback to at least one other submission.

Do not commit solutions to the DevSphere repository.

## 7. Evaluation rubric

| Criterion | Points | What reviewers look for |
| --- | ---: | --- |
| Core requirements | 40 | All required features are present and working |
| Responsive behavior | 15 | Layout works at small, medium, and large widths |
| Accessibility | 15 | Semantics, keyboard access, focus, contrast, alt text |
| Visual design | 10 | Hierarchy, spacing, typography, and consistency |
| Code quality | 10 | Readable structure and appropriate complexity |
| Communication | 10 | README, screenshots, and reflection are clear |
| **Total** | **100** | |

Adjust the weights only if the challenge's learning objectives justify it. Explain any change.

## 8. Definition of done

A submission is complete when:

- [ ] Every core requirement is implemented.
- [ ] The layout works from 320px to at least 1440px.
- [ ] Keyboard navigation and focus states are verified.
- [ ] Color contrast meets WCAG AA for normal text.
- [ ] Images have appropriate alt text.
- [ ] No secrets or private data are included.
- [ ] The repository has a README with setup instructions.
- [ ] The reflection explains at least one trade-off.
- [ ] The submission is posted in the correct discussion category.

## 9. Rules and integrity

- Original implementation; credit tutorials, assets, and reused code.
- Free tools only.
- No plagiarism, harassment, or vote manipulation.
- Disclose substantial AI assistance and verify all generated code.
- Follow the [Code of Conduct](../CODE_OF_CONDUCT.md) and [Community Guidelines](../community/COMMUNITY_GUIDELINES.md).
- Never publish another person's private data.

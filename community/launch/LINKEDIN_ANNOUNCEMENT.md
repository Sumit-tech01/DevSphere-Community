# LinkedIn Announcement — DevSphere Recognition Campaign

> **Draft social post.** Publish manually from the founder's LinkedIn account. Do not post automatically. Re-check every link immediately before publishing.

## Main post

> Today I'm opening DevSphere's first community recognition campaign.
>
> DevSphere is a free, GitHub-native community for developers who learn by building in public. The new campaign is a consent-first way to notice the work that usually goes unseen: the documentation fix, the careful review, the first working prototype, the patient answer to a beginner's question.
>
> There are four parts:
>
> - Developer Spotlight: a written profile of a developer and a project they choose to share.
> - Project Review Friday: specific, constructive feedback on a community project.
> - Builder of the Month: monthly recognition for contribution, learning progress, and project development.
> - Community Collaboration: help finding collaborators, reviewers, and teammates.
>
> No one is featured yet. There is no shortlist and no quota. The first profile will be published only after a nomination, an evidence review, a private invitation, and the person's explicit approval.
>
> If someone's work helped you, ask them first and then nominate them. If you are building something, bring one project and one question to Project Review Friday. If you want to be considered, you can nominate yourself.
>
> Start here: https://github.com/Sumit-tech01/DevSphere-Community/blob/main/community/DEVELOPER_SPOTLIGHT.md
>
> #DevSphere #DeveloperCommunity #OpenSource #BuildInPublic

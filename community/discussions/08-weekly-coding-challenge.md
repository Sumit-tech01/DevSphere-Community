# Weekly Coding Challenge — Build a Responsive Developer Profile Card

This week's challenge is practical, visual, and beginner-friendly:

**Build a responsive developer profile card.**

The full brief is [Challenge 001](https://github.com/Sumit-tech01/DevSphere-Community/blob/main/challenges/challenge-001.md). This thread is for questions, progress updates, and encouragement while you work through it.

## Why this challenge?

A profile card looks simple, but it touches many real skills:

- Semantic HTML.
- Responsive layout.
- Typography and visual hierarchy.
- Color contrast and accessibility.
- Keyboard navigation.
- Documentation and reflection.

It is a small enough project to finish and a rich enough project to learn from.

## The core requirements

Your card should include:

- [ ] A profile image or avatar.
- [ ] Name, role, and a short bio.
- [ ] At least four skills.
- [ ] Location or time zone and availability.
- [ ] At least three accessible links.
- [ ] A layout that works at 320px, 768px, and 1440px.
- [ ] Visible focus states and keyboard access.
- [ ] WCAG AA color contrast.
- [ ] Reduced-motion support for any animation.
- [ ] A README with a screenshot and one design decision.

Read the [full brief](https://github.com/Sumit-tech01/DevSphere-Community/blob/main/challenges/challenge-001.md) for the complete requirements and rubric.

## Suggested weekly rhythm

| Day | Focus |
| --- | --- |
| Day 1 | Plan the content, sketch the layout, choose the type and color direction |
| Day 2 | Write semantic HTML and the content structure |
| Day 3 | Build the base layout and visual system |
| Day 4 | Add responsive breakpoints and test at 320px, 768px, and 1440px |
| Day 5 | Audit accessibility: keyboard, focus, contrast, alt text, reduced motion |
| Weekend | Polish, write the README, record a screenshot, and share your reflection |

You do not have to follow this schedule. It is a suggestion for people who want structure.

## Share your progress

## Submit your work

When you are ready, create a **Project Showcase** discussion titled:

```text

```

Include:

- Repository link.
- Live demo, if available.
- Screenshots.
- The requirements you completed.
- Bonus features you attempted.
- A short reflection.
- A self-assessment against the rubric.

Do not open a pull request against the DevSphere repository with your solution. Challenge solutions are shared in Discussions.

## Feedback

Give at least one other participant specific, kind feedback. Use the rubric as a shared reference, but explain your reasoning. "The focus ring is clear, but the skills list gets cramped below 360px" is more useful than "looks good."

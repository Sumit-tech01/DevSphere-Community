# DevSphere Learning Resources

A free, curated collection of learning material for developers at every stage. Every entry points to official documentation, recognized open-source projects, or genuinely useful educational resources.

> **Principles:** useful in practice, honest about access, actively maintained where possible, and free of paid placements or affiliate links. Paid resources are labeled only when they are clearly relevant and useful; the free path never depends on buying them.

## How to use this collection

1. **Start with the roadmap for your role.** It gives the sequence and the reason for each stage.
2. **Use the official tutorial for your language or tool.** It is usually the most accurate and up-to-date source.
3. **Build something small after each concept.** Reading without practice rarely sticks.
4. **Use documentation as a reference, not a novel.** Learn to search it efficiently.
5. **Follow one path at a time.** Collecting resources is not the same as learning.
6. **Share what you learn.** Write a short note, answer a question, or present a small demo.

## Status labels

| Label | Meaning |
| --- | --- |
| **Free** | The linked resource is free to access. |
| **Free + paid** | A free plan or free core exists; optional paid plans are also offered. |
| **Paid** | The resource requires payment. Included only when clearly relevant and labeled. |
| **Docs free; usage billed** | Documentation is free, but using the service may cost money. |
| **Free student resources** | Free resources with eligibility requirements. |

DevSphere does not list a resource as free unless the official page supports that description. Prices and plan limits change; verify them before relying on a free tier.

## Selection criteria

A resource is included only when it meets most of these criteria:

- **Useful:** it helps someone learn, build, or work more safely.
- **Accessible:** the free path is usable without a mandatory purchase.
- **Authoritative:** it is official, maintained by recognized practitioners, or a stable community reference.
- **Accurate:** it is consistent with current documentation or clearly versioned.
- **Maintained:** it is updated, or it has durable archival value.
- **Original:** it is not pirated, scraped, or an auto-generated link farm.
- **Safe:** it does not distribute malware or request unnecessary credentials.
- **Non-duplicative:** it adds something the collection does not already cover.
- **No affiliate or referral links.**

Some resources offer optional paid certificates, hosting, or plans. The free learning path must remain usable without payment, and optional upgrades are not required by DevSphere.

## Verification

Links are checked when the collection is updated and during periodic maintenance. If a link is broken, outdated, mislabeled, or no longer free, please report it through the [resource submission process](../community/RESOURCE_SUBMISSION.md).

## Suggest a resource

Read the full [resource submission process](../community/RESOURCE_SUBMISSION.md), then:

1. Confirm the link works without tracking parameters or a hidden paywall.
2. Check that it is not already listed.
3. Prefer the official source over a content farm.
4. State the category, level, and free or paid status accurately.
5. Explain who it helps and why it belongs.
6. Disclose any affiliation.
7. Open a [feature request](https://github.com/Sumit-tech01/DevSphere-Community/issues/new?template=feature_request.md) or a pull request following [CONTRIBUTING.md](../CONTRIBUTING.md).

## Important note

DevSphere does not control third-party sites. Content, availability, and pricing can change. Verify important information against the official documentation for your version and platform. Never share credentials, private data, or identity documents with an external learning platform.

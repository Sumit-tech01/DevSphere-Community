# Programming Resources

A curated path through programming languages, core computer science, and engineering practice. Start with one language, build small projects, and add depth over time.

> All resources are free to access. Optional certificates or paid upgrades are not required. See the [resource index](README.md) for selection criteria.

## Suggested learning sequence

1. **Choose one language** and complete its official tutorial.
2. **Learn Git and GitHub basics** from the [open-source collection](open-source.md).
3. **Build three small projects** that each teach a different concept.
4. **Add tests** and learn to debug failures methodically.
5. **Read other people's code** and make a small contribution.
6. **Study data structures and algorithms** as your projects grow.
7. **Learn one database, one API style, and one deployment path.**
8. **Teach what you learn** in a discussion, blog post, or short talk.

## Avoid

- Tutorial hopping without building anything.
- Copying code you cannot explain.
- Chasing every framework before fundamentals.
- Comparing your progress to someone with different constraints.
- Paying for "guaranteed" jobs, certificates, or shortcuts.
